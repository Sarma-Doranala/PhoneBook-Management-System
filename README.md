# PhoneBook Management System

A menu-driven Contact Management System developed using **C Programming**. The application uses a **Singly Linked List** for dynamic contact management and **File Handling** for persistent data storage.

## Features

- **Create Contacts:** Add new contacts with multiple phone numbers and email addresses.
- **Search Contacts:** Find contacts using available contact details.
- **Edit Contacts:** Update existing contact information.
- **Delete Contacts:** Remove contacts from the phonebook.
- **Duplicate Detection:** Handle duplicate contact entries.
- **Display Contacts:** View saved contact information.
- **Data Persistence:** Store and retrieve contact details using file handling.

## Technologies Used

- C Programming
- Singly Linked List
- Structures
- Dynamic Memory Allocation
- File Handling
